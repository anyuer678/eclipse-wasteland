# ECLIPSE 荒原防线

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)

浏览器端 FPS PVE 射击游戏：多波次副本、无尽爬塔、Roguelite 局内成长与深度养成系统。

集百家之所长的设计：武器机制、数值体系、敌人设计与养成框架的灵感来自多款经典射击与 Roguelite 游戏，经过重新设计与融合，形成一套原创的 PVE 玩法循环。

## 玩法

- **副本**：废弃设施 / 废弃矿场 / 地下实验室，多波次 PVE，通关结算
- **试炼之塔**：无限层爬塔，难度持续递增；精英层（每 3 层）与补给层（每 7 层）制造节奏起伏
- **局内成长**：击杀升级 → 三选一强化（12 种局内 BUFF 可叠加），每局独立构筑
- **敌人**：7 种兵种（追击 / 自爆 / 喷毒 / 盾兵 / 狂战 / 冰霜兽 / 弹幕法师）+ 精英词缀（狂怒/厚甲/再生）+ 2 个 BOSS
- **武器**：10 把 × 10 种机制（能量爆发 / 形态切换 / 索敌 / 减速 / 蓄力 / 光束 / 连锁闪电 / 治疗 / 三连发 / 穿透）
- **角色**：5 名（影袭者隐身 / 机甲师召唤 / 炎术士灼烧场 / 圣徒治疗场 / 狂战士狂暴）
- **养成**：武器同步 / 进阶 / 符文词缀 / 附魔 / 巅峰突破 + 天赋树 + 角色强化 + 每日任务 + 成就
- **战斗细节**：弹道亮线 / 伤害数字 / 连杀 / BUFF 球 / 高地加成 / 可破坏箱 / 毒池陷阱 / 局内商店（Tab）

## 运行

```bash
npm install
npm run dev    # 开发服务器（默认 http://localhost:5173）
npm run build  # 类型检查 + 生产构建
```

## 操作

| 键 | 动作 |
|---|---|
| 鼠标左键 / 右键 | 射击 / 过载射击 |
| WASD / Space / Shift | 移动 / 跳跃 / 疾跑 |
| R | 换弹 |
| 1-5 / Q | 切换武器 |
| E | 过载形态 / 技能 |
| X | 角色大招 |
| Tab | 局内商店 |
| B | 仓库（战斗中可切换武器） |
| Esc | 暂停 / 返回 |

## 技术栈

| 层级 | 技术 |
|---|---|
| 渲染 | Three.js（程序化建模 + 开源 GLB 模型 + 阴影） |
| 语言/构建 | TypeScript + Vite（rolldown） |
| 存档 | localStorage（纯前端，无后端） |

## 项目结构

```
src/
  arsenal/   武器配表 / 弹道 / 持枪视角
  campaign/  任务流程 / BOSS / 波次
  growth/    养成（武器 / 天赋 / 角色 / 每日 / 成就）
  horde/     敌人定义 / 生成器
  play/      角色 / 局内商店 / 武器库
  render/    世界构建 / 材质 / 光照
  shell/     UI 外壳（菜单 / HUD / 各界面）
  main.ts    主循环
```

## 开发方式：AI 协同

本项目由 **DeepSeek（Reasonix）全程深度参与开发**：

- **资料搜集与设计**：由 DeepSeek 检索多款射击与 Roguelite 游戏的武器设计、数值体系与养成框架资料，整理成设计依据后落地为配表（`src/arsenal/defs.ts`、`src/horde/enemy.ts` 等集中管理）
- **武器/机制设计**：10 把武器的机制差异、敌人行为树、BOSS 招式、局内成长构筑均由 DeepSeek 设计并实现
- **用户主导**：玩家侧（@anyuer678）负责提出设计思路、修正数值与体验问题（如命中判定、地形高度、UI 布局），并全程把关功能迭代方向
- **质量保障**：代码审查（正确性/性能/存档安全）由 DeepSeek 子代理执行并修复

这是一个「AI 出方案与实现、人类定方向与打磨」的协作示例。
