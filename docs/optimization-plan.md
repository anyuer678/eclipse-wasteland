## 二、原则与门槛

1. **不破坏手感**：任何数值/节奏改动先探针量化（接敌时间、击杀密度、帧率），再调参。
2. **每项可回归**：纯逻辑补单测；涉及战斗/UI 用 `window.__ss` 探针 + 截图双验。
3. **每轮收口**：tsc + vitest + build + 线上 Pages 200；独立提交，CI 绿后 push。
